# HouseMate Figma Designs

This folder contains all the Figma design files for the HouseMate application.

## Design Files Overview

Based on the Figma designs provided, the following pages/components need to be implemented:

### 1. **Landing Page** (Desktop-2)
- Hero section with "ON DEMAND TRUSTED HOME SERVICES"
- Service chip selector (Cleaning highlighted)
- Character illustration with cleaning tools
- "BOOK SERVICE" and "BECOME AN EXPERT" CTAs
- Customer Login and Expert Login links in header

### 2. **Customer Registration** (Multi-step wizard)
- Step 1: Personal Information
- Step 2: Service Profile  
- Step 3: ID Verification
- Progress indicator with 3 steps

### 3. **Customer Login**
- Phone number + Password authentication
- Link to registration

### 4. **Customer Dashboard**
- Welcome message
- Quick action cards
- Service categories grid
- Recent bookings list

### 5. **Book A Service / Customer**
- Service selection
- Category browsing
- Service details
- Addon selection
- Address selection
- Booking type (ASAP/Scheduled)
- Payment integration

### 6. **My Bookings / Customer**
- List of all bookings
- Filter by status

- View details action

### 7. **Feedback / Customer**
- Rating system
- Review submission
- Expert rating

### 8. **Home/Dashboard / Customer**
- Similar to Customer Dashboard
- Personalized recommendations

### 9. **Expert Registration** (Multi-step wizard)

### 10. **Expert Dashboard & Take Action**

### 11. **Modify Booking / Customer**

## Design System

### Colors
- Primary: #667eea (Purple)
- Secondary: #764ba2 (Dark Purple)
- Accent: #1976d2 (Blue)
- Success: #4caf50 (Green)
- Warning: #ff9800 (Orange)
- Error: #f44336 (Red)

### Typography
- Headings: Bold, 24-36px
- Body: Regular, 14-16px
- Small text: 12-13px

### Components
- Cards with rounded corners (12-16px border-radius)
- Gradient backgrounds for hero sections
- Material Icons for iconography
- Responsive grid layouts
- Form validation with error states
